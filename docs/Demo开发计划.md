# 《猫猫罐头小铺》Demo 开发计划 v0.1

## 1. Demo 目标

先验证核心玩法闭环，而不是完整商业化版本。

当前优先级调整为：先完成“导入图片关卡素材 → 生成拼豆底图 → 链接入游戏试玩”的关卡生成器。这样先解决图片导入无法稳定生成关卡的困难点，再继续推进游戏本体。

本 Demo 需要让玩家直观看到：

- 进入游戏后的关卡入口界面
- 选择关卡 1/2/3 并导入对应关卡图片
- 设置宽度珠子数，高度根据图片比例自动计算
- 在固定拼豆板网格中缩放、移动导入图片
- 调整亮度、对比度、饱和度和图片采样偏移
- 控制是否显示颜色代码、网格线和 29×29 拼豆板分割线
- 点击“生成关卡图案”得到拼豆底图预览
- 生成后背景保持留白，不显示无效背景格子
- 关卡入口读取已生成关卡，并点击当前关卡进入游戏
- 关卡入口优先显示生成关卡时导入的原图缩略图
- 放大后的猫咪拼豆底图
- 由导入图片自动生成的拼豆底图
- 开局拼豆在猫咪轮廓内被打乱
- 点击棋盘拼豆时，拾取相邻同色连通组进入底部暂存格
- 点击暂存格拼豆，再点击棋盘目标格归位
- 正确归位后格子锁定
- 错放扣 10 秒
- 倒计时和胜利反馈
- 放大镜放大与平移查看

## 2. 当前技术方案

当前先使用静态 H5 + Canvas/DOM 搭建可玩 Demo，放在 `src/` 目录。

原因：

- 当前工作区内没有现成 Cocos Creator 工程。
- 静态 H5 可以最快验证玩法、点击节奏和 UI 尺寸。
- 确认方向后，再迁移为 Cocos Creator 3.8.x 工程。

正式技术方案：

| 项目 | 选择 |
| --- | --- |
| 游戏引擎 | Cocos Creator 3.8.x |
| 构建目标 | Web Mobile（H5） |
| 语言 | TypeScript |
| 最低适配 | 微信内置浏览器、移动端 Chrome/Safari |
| 分辨率 | 竖屏 750 × 1624（设计稿），等比适配主流手机 |

## 3. 初始关素材

- 参考图：`assets/design/cat-reference.png`
- 最新初始关使用用户提供的水彩猫咪图片：`assets/design/level-cat-watercolor.png`。
- Demo 运行时读取 `src/assets/level-cat.png`，根据图片比例和采样粒度自动生成棋盘。
- 若内置素材无法加载，生成器仍支持通过文件选择器手动导入图片。
- 白色背景不生成可操作拼豆。
- 非背景区域被归并为少量主色，并生成目标底图颜色格。
- 当前可玩 Demo 已替换为图片驱动生成关卡。
- 拼豆格需要明显放大，避免原图拼豆过小导致手机端难以点击。
- 目标底图色使用整格方形填充，错误拼豆覆盖时仍能从边缘看到正确目标色。

## 4. Demo 第一版范围

包含：

- 顶栏：金币、倒计时
- 棋盘区：猫咪轮廓拼豆
- 目标底图：方格整格填充，不使用圆形底色
- 放大镜：放大 20%，支持边界内平移，恢复时居中
- 暂存格：3 行 × 12 格
- 点击棋盘拼豆时，批量拾取相邻同色拼豆；单次最多拾取 12 个
- 道具栏占位：框选归位、清空槽位、消色
- 胜利弹窗

暂不包含：

- 真实广告
- 微信分享
- 手账编辑器
- 完整道具效果
- 多关卡系统
- 直接从截图运行游戏逻辑

## 5. 下一轮 Demo 替换任务

1. 调整图片采样粒度，找到“可读”和“可点”的平衡。
2. 优化颜色聚类，减少水彩渐变导致的碎色。
3. 为关卡生成器增加导出 JSON 功能。
4. 为游戏增加从 JSON 关卡文件读取的入口。
5. 后续迁移 Cocos 时，将图片采样生成逻辑改为 TypeScript 数据管线。

## 6. 生成器修复记录

- 生成结果改为“调色板 + 颜色代码矩阵”，避免每个格子存完整颜色对象导致性能和本地保存问题。
- 兼容旧版本地缓存中的颜色对象矩阵。
- 生成失败时给出明确提示，不再静默无反馈。
- 背景识别阈值放宽，减少浅色猫咪身体被误判为空白背景的情况。
- 本地存储空间不足时，保留当前生成结果并给出提示。
- 新增关卡入口界面，作为默认首页，读取生成器保存的关卡 1/2/3。
- 开局打乱改为局部打乱，让拼豆颜色仍大致接近原位置，降低难度。
- 局部打乱半径调整为 1，进一步降低开局混乱度。
- 开局保证没有拼豆已经处于正确目标格。
- 游戏棋盘背景改为留白，不显示无效背景格线。
- 暂存格选中拼豆后，点击正确目标色可批量填充相邻同色目标格。
- 游戏时长按关卡递增：第 1 关 10 分钟，第 2 关 15 分钟，第 3 关 20 分钟，公式为 `10 + (关卡数 - 1) × 5` 分钟。
- 倒计时只在试玩游戏界面运行；离开试玩游戏进入关卡入口或关卡生成器时清理计时器，不能在非游戏界面触发失败。
- 倒计时结束未通关时弹出失败弹窗，支持“再来一局”。
- 通关成功弹窗展示本关原图贴纸，带白色贴纸描边、放大入场和礼花彩带效果。
- 通关成功后按钮改为“下一关”，失败才显示“再玩一次”。
- 放大镜支持 100%-150% 滑杆缩放，放大状态下仍可点击拾取/放置拼豆。
- 放大镜只通过再次点击放大镜关闭，不因点击拼豆自动缩小；滑杆倍率保持不回弹。
- 移除正确归位后的绿色锁定圈，仅保留不可点击的锁定行为。
- 增加连续正确反馈，连续数达到 5 以上时预留音效接入点。
- 开局打散后会拆分过大的同色连通块，目标是让任一同色连通块不超过 12 个；拾取逻辑也用单次 12 个做兜底。
- 增加停滞提示：开始游戏后，玩家 10 秒没有点击拼豆棋盘时，短暂高亮最多 6 个未对应底色的拼豆。

## 7. 验收标准

1. 页面可以在浏览器打开并游玩。
2. 拼豆只出现在猫咪轮廓内。
3. 暂存格满时，不能继续从棋盘取拼豆。
4. 正确归位后格子锁定。
5. 错放扣 10 秒。
6. 全部格子正确后显示通关反馈。
