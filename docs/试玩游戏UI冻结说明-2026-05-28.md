# 试玩游戏 UI 冻结说明 - 2026-05-28

## 冻结结论

试玩游戏界面的主要美术资产位置、大小和布局已确认固定。后续默认不得改动试玩游戏主界面的布局坐标、资源尺寸和交互位置，除非用户明确要求继续调整该界面。

## 冻结范围

- 顶栏：玩家级数框、第 X 关标题、猫咪金币框、倒计时框、返回按钮。
- 棋盘区：放大镜、放大镜滑杆、棋盘框、实际棋盘可玩区。
- 暂存栏：暂存栏整体位置、暂存格排列、暂存格样式。
- 道具栏：框选归位、清空槽位、消色按钮的位置和尺寸。
- 成功弹窗：成功面板、当前关卡图、下一关按钮、隐藏文字规则。
- 移动端适配：480x853 固定设计画布与整体缩放方案。

## 暂不冻结范围

- 失败弹窗仍在继续调整中，允许继续替换素材和微调按钮位置。
- 第一关关卡图案因生成颜色异常已临时解冻，开发端允许用生成器重新保存 Level 1；Level 2-10 仍保持固定关卡。
- 新手指引尚在方案讨论阶段，确认方案后再进入实现。
