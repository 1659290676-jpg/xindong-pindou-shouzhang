## 发布流程

1. 修改后先运行：
   - `node --check src/main.js`
   - `node --check src/assets/levels/fixed-levels.js`
   - `git diff --check`
2. 暂存时显式指定文件，避免误提交无关删除。
3. 推送到 `main` 后 GitHub Pages 链接通常需要 1-3 分钟刷新。
4. 线上玩家页缓存版本在 `src/player.html` 中通过 `?v=...` 控制。

## 已知注意事项

- 浏览器或微信内置浏览器可能缓存旧 CSS/JS，用户测试时可重新打开链接或清缓存。
- Codex 浏览器插件不能直接访问 `file://` 页面，只能测试线上或普通 HTTP/HTTPS 页面。
- `gh auth status` 曾显示 GitHub CLI token 失效，但 `git push origin main` 当前可以通过系统凭据成功推送。
