# 试玩界面 UI 与道具迭代记录 - 2026-05-27

## 范围

- 本次只调整试玩游戏界面，不改动已冻结的关卡入口 UI。
- 设计源文件来自 `assets/design/gameplay-ui/`。
- 运行时素材已复制到 `src/assets/ui/gameplay/`，避免 `src/` 直接依赖设计目录。

## UI 调整

- 试玩界面改为 9:16 手机竖屏容器。
- 增加试玩界面最底背景、试玩界面底图、棋盘框、暂存栏框、顶栏金币框、倒计时框、玩家级数框、返回键和底栏三枚道具按钮素材。
- 原底部黑色提示条改为显示在棋盘与暂存栏之间，使用黑色文字且不显示黑色底框。
- 顶栏显示当前关卡标识：`第X关`。
- 右上角返回键可返回主页。
- 顶栏玩家级数框显示 `LV.X`，当前关卡 `第X关` 独立显示在玩家级数框与返回键之间。

## 道具规则

- 框选归位：点击道具后，在棋盘显示 6x6 彩虹选区；点击棋盘后将该区域内的拼豆尽量归位。
- 清空槽位：点击道具后选择暂存格颜色，将该颜色从暂存区尽量回填到正确底图格。
- 消色：点击后随机选择当前场上一种颜色，并将该颜色尽量归位。
- 弹框层级高于棋盘、放大镜和底栏道具，失败后点击“再玩一次”会关闭弹框并重开当前关。
- 框选归位的彩虹框改为棋盘绝对定位覆盖层，不参与棋盘网格排版。
- 暂存栏格子由 CSS 单独定位绘制，整张暂存栏素材作为底层装饰，避免拼豆落点受整图留白影响。
- 暂存栏格子改为固定正方形网格，避免纵向压缩或横向拉伸。
- `tray-frame-crop.png` 恢复上一版裁剪尺寸，不再强制调整为 3.64 比例。
- 暂存栏运行背景改用完整 `tray-frame.png`，通过背景定位显示在暂存栏区域，不再使用 `tray-frame-crop.png`。
- 成功弹窗接入 `成功弹窗—成功弹框`、`成功弹窗—叉按键`、`成功弹窗—下一关按键键` 运行时素材。
- 框选归位改为以 6x6 区域内的底图格为目标，点击后尽量让该区域内底图颜色和拼豆颜色对应。
