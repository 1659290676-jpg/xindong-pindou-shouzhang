# 导入图片生成拼豆底图方案 v0.2

## 1. 目标

关卡不再依赖固定棋盘尺寸，也不要求用户先提供标准化拼豆矩阵。

用户导入一张关卡图片后，系统将图片转换为：

- 拼豆目标底图
- 图案轮廓 mask
- 可移动拼豆颜色集合
- 开局打乱后的棋盘状态

当前 Demo 使用图片：

- 原始素材：`assets/design/level-cat-watercolor.png`
- Demo 运行素材：`src/assets/level-cat.png`

## 2. 当前 Demo 生成流程

1. 页面加载 `src/assets/level-cat.png`。
2. 生成器先建立一个固定拼豆板网格。
3. 导入图片会被绘制到固定网格画布中，支持缩放与水平/垂直移动。
4. 玩家可先把图片放大到合适的图案大小，再生成关卡图案。
5. 将固定网格切成若干采样格。
6. 对每个采样格进行像素分析：
   - 接近白色的区域视为背景。
   - 非背景区域视为图案轮廓内拼豆格。
7. 将采样出的颜色归并到少量主色。
8. 为每个非背景格生成一个方形目标底色。
9. 背景格不显示填充、不显示网格，保持留白。
10. 根据目标底色生成同等数量的圆形拼豆。
11. 开局时只在图案轮廓内打乱拼豆。
12. 玩家点击棋盘拼豆时，会一次拾取上下左右相邻的同色连通组。
13. 玩家从暂存格选择拼豆并放回正确目标色格后，该格锁定。

## 3. 当前参数

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| 目标采样列数 | 默认 50 | 用户可调整 |
| 目标采样行数 | 自动计算 | 根据图片比例自动计算 |
| 最大颜色数 | 默认 0 | 0 表示不限制，使用采样调色板 |
| 背景阈值 | RGB 大于 246 | 接近白色视为空白背景 |
| 最小有效像素占比 | 0.035 | 低于该占比的采样格视为空白 |
| 图片调整 | 图片缩放、水平移动、垂直移动、亮度、对比度、饱和度 | 用于修正导入图片的采样效果 |
| 暂存格 | 3 × 12 | 初始关降低难度 |

## 4. 显示规则

- 目标底色使用方格整格填充。
- 拼豆使用圆形表现。
- 错误拼豆覆盖目标格时，方形底色边缘仍需可见。
- 空白背景不生成填充，不显示网格，不可点击，不可放置。
- 放大镜模式下棋盘放大 20%，支持边界内平移查看。

## 5. 降低难度规则

由于图片生成的棋盘格数量较多，初始关新增批量拾取规则：

- 点击一个棋盘拼豆时，系统查找与它上下左右相邻、颜色相同、未锁定的拼豆。
- 这些拼豆作为一个同色连通组进入暂存格。
- Demo 阶段单次最多拾取 12 个；若暂存格剩余容量不足，则只拾取能放下的数量。
- 该规则能减少玩家重复点击，提高高密度图案的可玩性。

## 6. 后续优化

- 根据图片复杂度自动建议采样密度。
- 优化颜色聚类，避免水彩纹理被拆成过多碎色。
- 增加轮廓平滑规则，减少孤立单格。
- 增加关卡 JSON 导出和导入。
- 迁移到 Cocos Creator 3.8.x 后，用 TypeScript 实现同一套生成逻辑。
