# 游戏加载失败排查

## 现象

点击进入试玩游戏时，只出现“游戏加载失败”，玩家无法知道具体原因。

## 原因

`initGame()` 的异常被统一 catch 成固定文案，真实错误没有显示出来。当前项目会把生成关卡存入 `localStorage`，如果之前版本保存过结构不完整的关卡，例如缺少 `palette`、`matrix` 行列不一致、颜色 key 对不上调色板，开局打乱或渲染时就可能抛错。

## 处理

- 读取缓存关卡时做 `normalizeLevel()` 与 `isPlayableLevel()` 校验。
- 不可玩的旧缓存关卡会被删除，并回退到重新生成默认关卡。
- `initGame()` 增加关卡完整性检查，避免缺颜色、缺可拼区域时继续执行。
- 游戏加载失败时通过 `handleGameLoadError()` 输出真实错误，并在界面 toast 显示具体原因。

## 后续建议

开发调试阶段优先使用本地 HTTP 服务访问页面，减少 `file://` 对图片、控制台与资源调试的限制。
